# Stable update — 2026-10-14

## Resolved issues

- **#1:** The topbar and Briefing use the same unread chat and meeting notification count.
- **#2:** Meeting events open their full message and meeting date/theme. Read state is stored per account; read events remain available. Submitting an own update completes that member's progress reminders.
- **#3:** Active collaborators matched by account username can view project details, updates and attachments, and add comments. External name labels do not grant access. Editing, adding updates, archiving and deleting updates remain owner/PI/admin-only.
- **#5:** Missing meeting fields produce readable validation messages. Empty progress focuses the relevant field; nothing-to-report submissions may omit progress.

## Partially implemented

- **#4:** Owners and PI/admin can edit timeline updates and delete them after confirmation. Attached records become unavailable after deletion. Projects use reversible archive/restore; permanent project deletion remains outstanding.

## Theme meeting improvements

- Agenda emails include HTML and plain-text alternatives, a discussion table and separate Updates.
- Deep dives come first; common alphabetic, numeric and dash list markers render as consistent bullets.
- Meetings without discussion slots get an advisory skip suggestion, subject to coordinator/PI/admin confirmation.
- Short update is a distinct five-minute slot. Progress warns above 50 words and rejects new submissions above 75 words.
